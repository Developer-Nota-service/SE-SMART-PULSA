Hubungkan ke VPS

Pasang bridge Kantor Agent AI di VPS Anda (lihat perintah di bawah), lalu isi alamat dan token bridge-nya. Setelah tersambung, kantor ini menampilkan sesi Claude Code yang benar-benar berjalan di sana.

Percobaan memakai mode demo bawaan, jadi kantor tetap bisa dilihat tanpa VPS. Mode demo tidak menjalankan Claude Code.

Pasang di HP

Buka halaman ini di Chrome (Android) atau Safari (iPhone), lalu pilih Instal aplikasi / Tambahkan ke Layar Utama. Aplikasi berjalan layar penuh seperti aplikasi biasa.

Server di VPS (Claude Code)

  1. Unduh repo ini di VPS, lalu jalankan sebagai root: sudo bash office/install-kantor-bridge.sh
  2. Installer membuat service systemd, token, dan (opsional) vhost Nginx + HTTPS.
  3. Aktifkan eksekusi: sudo bash office/install-kantor-bridge.sh --enable-run
  4. Pasang hook Claude Code supaya aktivitas sesi tampil di kantor ini: node office/bridge/install-claude-hooks.mjs

Panduan lengkap: docs/KANTOR-OFFICE-MOBILE.md
